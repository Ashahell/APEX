# v1.9.0 Release Notes - Alert Escalation & Analytics

> **Version:** v1.9.0  
> **Date:** 2026-04-16  
> **Status:** Released

---

## Overview

v1.9.0 introduces **Alert Escalation** and **Historical Analytics** features, along with **Death Spiral Detection Integration** for automatically creating alert rules from detected execution patterns.

---

## New Features

### 1. Alert Escalation System

Automatically escalate unacknowledged alerts based on configurable time thresholds.

**Backend Models:**
- `EscalationLevel` - level number, wait_secs, actions
- `EscalationConfig` - enabled flag, max_level, default_wait_secs
- Alert model extended with `escalation_level`, `escalated_at`, `last_escalation_at`

**API Endpoints:**
- `GET /api/v1/vigilant/escalation/pending` - Get alerts pending escalation
- `POST /api/v1/vigilant/escalation/process` - Process escalations

**Actions per level:**
- Level 1 (5min): Notify + Email
- Level 2 (10min): ExecuteCommand
- Level 3 (immediate): CancelTask

### 2. Historical Analytics

Charts for alert trends with hourly buckets, average times, and top rules.

**Backend Models:**
- `AlertAnalytics` - total_alerts, by_severity, by_status, hourly_buckets
- `HourlyBucket` - hour, count, critical, warning, info counts
- `DetectedPattern` - pattern grouping from death spiral detection

**API Endpoints:**
- `GET /api/v1/vigilant/analytics?hours=24` - Get alert analytics

**UI Components:**
- Analytics tab with hourly trend chart
- Severity breakdown (Critical/Warning/Info)
- Status breakdown (Active/Acknowledged/Resolved)
- Average acknowledge and resolve times

### 3. Death Spiral Detection Integration

Auto-create alert rules from detected execution patterns.

**Pattern Types Detected:**
- `tool_call_loop` - Infinite tool call loops
- `no_progress` - No progress after N steps
- `error_cascade` - Multiple sequential errors
- `file_creation_burst` - File creation bursts
- `timeout_warning` - Task timeout warnings

**API Endpoints:**
- `GET /api/v1/vigilant/patterns/suggestions` - Get rule suggestions from patterns
- `POST /api/v1/vigilant/patterns/create-rule` - Create alert rule from pattern

**UI Components:**
- Pattern Suggestions tab showing confidence scores
- One-click rule creation from suggestions
- Only suggestions with 2+ occurrences shown
